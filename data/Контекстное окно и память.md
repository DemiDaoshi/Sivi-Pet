# Контекстное окно и управление рабочей памятью модели

## Что такое контекстное окно
- **Рабочая память модели**, ограниченная по количеству токенов.
- Включает: системные инструкции, историю переписки, текущий запрос, дополнительные данные (результаты вызова tools).

## Пример
- Агент ClaudeCode загружает несколько файлов и выполняет команды терминала.
- Это быстро потребляет тысячи токенов контекста.

## Проблема переполнения
При переполнении модель:
- забывает ранее важную информацию;
- игнорирует инструкции;
- повторяется;
- запрашивает уже открытые файлы.

## Сжатие контекста
- Автоматическая суммаризация работает, но теряет подробности.
- Для архитектурных решений потеря деталей критична.
- Рекомендуется **ручная или продуманная организация контекста**.

## Работа с API
- Самостоятельно управлять историей и контекстом.
- Разбивать задачи на новые сессии с выдержанным резюме.
- **Tools** съедают контекст особенно быстро → нужен проактивный контроль.
