# Тренинг, инференс и память моделей

## Training
- Длительный процесс.
- Миллионы и терабайты данных.
- Обновление весов модели с помощью GPU-ферм.

## Inference
- Использование модели для ответов.
- Веса **не меняются**.

## Память ChatGPT
- Не обучается на данных пользователя в реальном времени.
- Хранит информацию лишь в пределах сессии и явной «памяти» (history).

## Данные и обучение
- Провайдеры могут использовать данные для будущего обучения.
- Для чувствительной информации: приватные модели, проверка настроек.
