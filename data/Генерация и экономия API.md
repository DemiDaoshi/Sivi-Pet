# Механизмы генерации ответов и экономия на API

## Два этапа генерации
1. **Префилл (parallel fill)** — обработка всего входного промта параллельно.
2. **Декод (decode)** — последовательное пошаговое формирование текста.
   - Каждый токен зависит от предыдущих.
   - Не может быть сгенерирован параллельно.

## Почему output дороже input
- Пересчёт внимания для всех предыдущих токенов медленный.
- Решение — **K-value cache** (кэш внимания).
- Пример цен ClaudeCode:
  - input: **$3 за 1 млн токенов**;
  - output: **$15 за 1 млн токенов**;
  - вывод примерно **в 5 раз дороже**.

## Кэш
- Снижает стоимость на **70–90%** при многократной работе с одними и теми же данными.

## Batch-обработка
- API с поддержкой batch (например, **Anthropic Batching**) дают **50% скидки**.
- Подходит для несрочных задач.

## Пример расчёта
- 1000 запросов, 10 100 токенов входа, 500 токенов выхода.
- Без кэша: **$1100/мес**.
- С кэшем: **$300/мес**.
- С batch: около **$150/мес**.
