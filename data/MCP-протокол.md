# MCP-протокол: стандарт подключения AI к системам

## Проблема
- Раньше для каждого инструмента писали отдельный адаптер.
- Куча кода и хаос.

## Решение
- В конце 2024 года Anthropic предложил **Model Context Protocol (MCP)**.
- Единый стандарт подключения AI к системам.
- Аналогия: **USB-C для агентов**.
- Один протокол — AI понимает, как общаться с любым сервисом.

## Три примитива
1. **Tools** — действия: запуск кода, запрос к API, работа с файлами.
2. **Resources** — данные только для чтения: документы, файлы, любые данные.
3. **Prompts** — шаблоны системных инструкций для типовых запросов.

## Главная фича
- Агент **сам узнаёт**, какие действия ему доступны.
- Никаких хардкодных интеграций.
- Всё работает через **JSON-RPC 2.0**.
